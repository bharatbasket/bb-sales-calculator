# Bharat Basket Dealer Rate Calculator

Open `index.html` in any browser.

Current default ex-factory rates:
- Packing ₹163.53/L
- 15L ₹2,432.09/tin
- 15Kg ₹2,661.25/tin
- 13Kg ₹2,321.75/tin
- Kachi Ghani 1L ₹167.53/L

Transport slabs are fixed as supplied by Bharat Basket.
GST = 5%.

Important: this prototype stores updated rates in the browser's local storage. For a true shared live URL where one admin update reaches every salesman, connect the admin rates to a small database/backend during deployment.
